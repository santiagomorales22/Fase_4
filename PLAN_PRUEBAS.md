
# PLAN DE PRUEBAS - FASE 4

## 1. Objetivo
Verificar el funcionamiento de los módulos del sistema de software.

## 2. Pruebas funcionales

| Módulo | Prueba | Resultado esperado |
|---|---|---|
| Clientes | Registrar un cliente | Cliente registrado correctamente |
| Entidades | Consultar entidades | Mostrar información disponible |
| Reservas | Consultar una reserva | Mostrar los datos de la reserva |
| Servicios | Consultar servicios | Mostrar los servicios disponibles |
| Excepciones | Validar datos incorrectos | Controlar los errores |
| Logs | Registrar eventos | Guardar los eventos del sistema |

## 3. Observaciones
Las pruebas permiten identificar posibles errores y verificar el comportamiento de los módulos.

## 4. Conclusión
El plan de pruebas contribuye a la verificación y documentación del funcionamiento del sistema.
